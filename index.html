  1. Klik Buat Data Simulasi Baru untuk melihat contoh, atau Unggah CSV berisi kolom sku, nama, permintaan, harga.
  2. Atur batas kelas A dan B (standar 80% dan 95%).

  4. Fokuskan cycle count, pengamanan, dan penempatan dekat area outbound untuk kelas A.
  5. Unduh hasil sebagai CSV untuk dibuka di Excel.
Petunjuk penggunaan
  1. Isi permintaan tahunan, biaya pesan, harga, dan persentase biaya simpan (umumnya 15–30%).
  2. Isi lead time pemasok dan variasi permintaan harian untuk menghitung safety stock.
  3. EOQ = jumlah pesan yang meminimalkan total biaya. ROP = saat stok menyentuh angka ini, buat PO.
  4. Grafik menunjukkan total biaya turun mendekati EOQ, lalu naik lagi.

Petunjuk penggunaan

  2. Target okupansi 80–90% disarankan agar ada ruang gerak dan fleksibilitas.
  3. Hasil menampilkan jumlah bay, baris, dan estimasi luas area rak + lorong (belum termasuk dock dan kantor).
  4. Coba ubah jumlah level untuk membandingkan: rak lebih tinggi = area lebih kecil, tetapi butuh alat angkat lebih tinggi.

Pertanyaan umum

Apakah data saya aman?

Semua perhitungan berjalan di browser kamu. Tidak ada data yang dikirim ke server mana pun.

Apakah perlu internet?

Semua perhitungan berjalan di browser. Internet dipakai hanya untuk memuat pustaka grafik saat halaman dibuka.

Bisa dipakai di Excel / Google Sheets?

Ya. Semua hasil bisa diunduh sebagai CSV dan dibuka di Excel atau Google Sheets.

Apa yang saya terima setelah membayar?

File HTML lengkap (tanpa batasan demo, unggah & unduh CSV aktif), panduan penggunaan, dan lisensi. File dikirim lewat WhatsApp atau email setelah pembayaran terkonfirmasi.

Apakah data di demo ini asli?

Bukan. Seluruh data dibuat acak oleh generator simulasi untuk keperluan demonstrasi.
