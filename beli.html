Pesan aplikasi

Pilih aplikasi, isi nama pembeli, lalu kirim pesanan lewat WhatsApp. Sekali bayar, tanpa langganan.

1. Pilih aplikasi

Mau mencoba dulu? Setiap aplikasi punya demo di browser, tanpa unduh dan tanpa daftar.

2. Data pembeli

Nama ini ditanamkan pada aplikasi edisi lengkap (pada judul dan dokumen cetak), jadi tulis dengan benar.

Alur pemesanan

  1. Kirim pesanan
    Tombol "Kirim pesanan" membuka WhatsApp dengan pesanan yang sudah terisi.
  2. Konfirmasi dan pembayaran
  3. Terima file
    Installer Windows (.exe) atas nama pembeli, ditambah folder HTML sebagai cadangan.
  4. Mulai pakai
    Instal, lalu isi data perusahaan Anda sendiri. Data tersimpan di komputer Anda.

Ketentuan

  • Sekali bayar, tanpa langganan bulanan.
  • Aplikasi diberikan sebagaimana adanya: tanpa garansi, layanan pembaruan, atau dukungan WhatsApp.
  • Untuk Windows 10/11. Berjalan tanpa internet, data disimpan di komputer pembeli.
  • Windows dapat menampilkan peringatan "Windows protected your PC" karena aplikasi belum bertanda tangan digital. Pilih More info lalu Run anyway.
  • Cadangkan data secara berkala lewat menu Pengaturan di setiap aplikasi.
