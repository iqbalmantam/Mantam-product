FAQ

Pertanyaan umum

Apakah data saya aman?

Tool HTML berjalan di browser kamu dan tidak mengirim data ke server. Workbook Excel adalah file lokal milikmu.

Apakah perlu internet?

Perhitungan berjalan lokal. Internet hanya dipakai untuk memuat pustaka grafik pada tool HTML; workbook Excel tidak membutuhkannya.

Excel versi berapa yang dibutuhkan?

Excel 2010 atau lebih baru. Workbook tidak memakai makro maupun fungsi baru (XLOOKUP, FILTER), jadi juga terbuka di LibreOffice dan Google Sheets.

Apa bedanya demo dan versi lengkap?

Demo memakai data simulasi dengan kapasitas dan fitur terbatas. Versi lengkap membuka kapasitas penuh, dashboard, ekspor, serta fitur tambahan, dan dikirim sebagai file terpisah setelah pembayaran.

Apakah tes psikologi ini baku?

Bukan. Tes kepribadian, minat, dan kemampuan adalah alat refleksi dan skrining awal dengan bank soal contoh; bukan alat diagnosis dan tidak menggantikan asesmen psikolog. Perhitungan lembur dan akuntansi juga bersifat estimasi; cocokkan dengan peraturan dan kebijakan perusahaan.

Apakah data di demo ini asli?

Bukan. Seluruh data dibuat oleh generator simulasi untuk keperluan demonstrasi.
